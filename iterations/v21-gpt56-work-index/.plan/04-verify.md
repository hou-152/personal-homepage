# Phase 04 Verify

Status: pending

## Goal

验证 V21 构建、桌面 / 手机布局、内容长度、链接和隐私边界。

## Preconditions

- 用户验收 Phase 3。

## Acceptance Criteria

- `npm run build` 通过，或 blocker 被明确诊断。
- 桌面首页不是空白、破版或横向溢出。
- 390 × 844 手机页面无文字遮挡、按钮挤压和横向溢出。
- 手机 Hero 目标高度不超过 900px。
- 手机总高目标约 8–10 屏。
- 桌面总高目标不超过约 4800px。
- 首页主内容链接不超过 18 个。
- 首页只有一个完整 AI 内参主案例。
- 所有项目入口有效。
- 构建产物不包含私有仓库内容或聊天原料。
- 新截图保存在项目既有截图职责目录中。

## Tasks

- [ ] 运行 production build。
- [ ] 启动本地静态预览。
- [ ] 检查桌面布局和总高度。
- [ ] 检查 390 × 844 手机布局和总高度。
- [ ] 检查导航、项目和联系链接。
- [ ] 搜索构建产物中的敏感词和私有项目名。
- [ ] 记录截图和验证结果。
- [ ] 停止并等待用户最终验收。

## Notes

AGENTS 记录过 V16 后本地 production build 卡住。若问题再次出现，必须记录诊断，不得用开发服务器成功替代 production build 结论。
